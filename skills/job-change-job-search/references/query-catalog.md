# 無償の公開Web検索による求人探索カタログ（query-catalog）

無償の公開Web検索だけで求人を探すためのカタログである。掲載する各サイトは、検索結果ページがログインなしで閲覧できることを実際に確認したものに限る。確認できなかったサイトは載せない。求人検索担当エージェント（job-change-job-searcher）は、WebSearch・WebFetch でこれらをたどり、掲載ページの引用とURLを付して結果を集める。

**確認日**: 2026-07-17（この日付時点で各サイトのログイン要否・URL構造を確認した。サイト側の仕様変更により、本カタログの記載と実態がずれうる。取得できない項目は成果物の `coverage_notes` に記す。）

**共通の制約**
- 会員登録・ログインが必要な「非公開求人」は無償の公開検索の範囲外とする。範囲外にした旨は `coverage_notes` に記す。
- 掲載ページの文言はそのまま `quote` に写す。取得できない求人を創作しない。
- 給与が「応相談」等で数値が読めない求人は `salary_range` を `null` にする。

## 1. 求人ボックス（kyujinbox.com）

株式会社カカクコムが運営する求人検索エンジン。国内の求人を横断的に集約する。

| 観点 | 内容 |
|---|---|
| ログイン要否 | 検索・一覧の閲覧はログイン不要（確認済み）。 |
| URLの組み立て | 検索条件はURLパス内に日本語をURLエンコードして埋め込む形式である。トップページ（`https://求人ボックス.com/`。Punycode 形式は `https://xn--pckua2a7gp15o89zb.com/`）から、職種・勤務地・雇用形態のリンクをたどると、`/{条件}の仕事`（例: 「東京都での仕事」「医療事務の仕事」）や `/転職/` のようなパスへ遷移する。詳細条件検索は `/adv/`（`https://求人ボックス.com/adv/`）にある。 |
| 取得できる項目 | 求人タイトル・企業名・勤務地・給与・雇用形態など、一覧に表示される項目。 |
| 制約・縮退（フォールバック） | 条件がURLパスへ日本語エンコードで入るため、URLの機械的な組み立てより、トップ・`/adv/` から検索して結果ページのURLを得るたどり方が安定する。取得できない詳細は掲載元リンク先を `WebFetch` で確認する。 |

## 2. Indeed 日本（jp.indeed.com）

求人検索エンジン。クエリパラメータで検索でき、無償公開検索では最も機械的に扱いやすい。

| 観点 | 内容 |
|---|---|
| ログイン要否 | 検索結果の閲覧はログイン不要（確認済み。求人タイトル・企業名・給与・勤務地・雇用形態が取得でき、CAPTCHA・bot検知によるブロックは確認時点では発生しなかった）。 |
| URLの組み立て | `https://jp.indeed.com/jobs?q={キーワード}&l={勤務地}` の形式。`q` がキーワード（職種名・スキル名）、`l` が勤務地。値はURLエンコードする。例: `q=バックエンドエンジニア`・`l=東京都` → `https://jp.indeed.com/jobs?q=%E3%83%90%E3%83%83%E3%82%AF%E3%82%A8%E3%83%B3%E3%83%89%E3%82%A8%E3%83%B3%E3%82%B8%E3%83%8B%E3%82%A2&l=%E6%9D%B1%E4%BA%AC%E9%83%BD`。 |
| 取得できる項目 | 求人タイトル・企業名・給与（月給・年俸の表記）・勤務地・雇用形態。 |
| 制約・縮退（フォールバック） | アクセス頻度が高いと bot 検知が働きうる。ブロックされた場合は、後述の検索エンジン経由（`site:jp.indeed.com` 検索）や別サイトへ縮退する。給与が「月給」表記の求人は年収換算の可否を `match_notes` に明記する。 |

## 3. Green（green-japan.com）

IT・Web業界に強い転職サイト。

| 観点 | 内容 |
|---|---|
| ログイン要否 | 求人一覧・検索結果の閲覧はログイン不要（確認済み。求人カードが表示される）。 |
| URLの組み立て | 検索は `https://green-japan.com/search` を起点とする。ページ送りは `?page=2` の形式。職種・勤務地・キーワードの絞り込みUIはあるが、絞り込み条件のクエリパラメータ名は固定と確認できていないため、URLの機械組み立てには依存しない。 |
| 取得できる項目 | 求人タイトル・企業名など、一覧カードに表示される項目。 |
| 制約・縮退（フォールバック） | このサイトは Next.js で動的に描画するため、絞り込み結果の一部は JavaScript の実行後に確定する。`WebFetch` で読めるのはサーバー描画済みの範囲に限られる。絞り込みが効かない場合は、`site:green-japan.com {職種} {勤務地}` の検索エンジン経由で個別求人ページへたどり、`WebFetch` で内容を確認する縮退を用いる。 |

## 4. type（type.jp）

キャリアデザインセンターが運営する転職サイト。

| 観点 | 内容 |
|---|---|
| ログイン要否 | 職種・条件別の求人カテゴリの閲覧はログイン不要（確認済み）。 |
| URLの組み立て | フリーワードのクエリではなく、構造化されたカテゴリパスでたどる設計である。職種別は `/job-1/`（IT・Web）・`/job-5/`（営業系）等の大分類、さらに `/job-1/1001/`（システムエンジニア）・`/job-1/1001/3/`（Webバックエンドエンジニア）のように細分化する。勤務地別は `/job-area1/`〜`/job-area9/`、年収別は `/job-salary/`、業種別は `/job-industry/`、こだわり条件は `/job-condition/`。職種一覧の入口は `/s/job/`。 |
| 取得できる項目 | カテゴリ配下の求人タイトル・企業名など、一覧に表示される項目。 |
| 制約・縮退（フォールバック） | フリーワード検索が前面に無いため、まず職種・エリアのカテゴリパスへたどってから一覧を読む。カテゴリ番号が不明な場合は `/s/job/` や `site:type.jp {職種}` の検索エンジン経由で該当カテゴリのURLを得る。 |

## 縮退（フォールバック）の共通手段

サイトが動的描画・bot検知・URL構造の非公開などで直接たどれないときは、次へ縮退する。

| 手段 | 内容 |
|---|---|
| 検索エンジンの `site:` 演算子 | `WebSearch` で `site:{ドメイン} {職種} {勤務地} {条件語}` を検索し、個別求人ページのURLを得てから `WebFetch` で内容を読む。例: `site:jp.indeed.com バックエンドエンジニア 東京 リモート`。動的描画サイトでも、個別求人ページはインデックスされていることが多い。 |
| 別サイトへの代替 | 1サイトで取得できない条件は、本カタログの他サイトで代替する。取得元サイトは各 result の `source_site` に必ず記す。 |
| 取得限界の明示 | どのサイトのどの範囲を対象にし、何を範囲外にしたか（会員限定の非公開求人・動的描画で読めなかった絞り込みなど）を `coverage_notes` に記す。 |

いずれの手段でも、掲載ページの引用 `quote` とURLを付し、取得できない求人を創作しない原則を保つ。
