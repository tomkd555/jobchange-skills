# 受検案内 URL による検査系統の事前判別

受検案内メールや受検ページの URL のドメインから、検査の系統をある程度事前に判別できる。Step 0 で URL があるとき、および Step 2 で暫定判別と Step 1 の調査結果を照合するときに使う。

## 判別表

| URL に含まれるドメイン文字列 | 判別できる系統 | 対応する検査 |
|---|---|---|
| `arorua.net` | リクルート系 | SPI（テストセンター／WEB テスティング） |
| `e-exam` | 日本 SHL 系 | 玉手箱・GAB・CAB のいずれか |
| `nsvs` | 日本 SHL 系 | 玉手箱・GAB・CAB のいずれか |
| `tsvs` | 日本 SHL 系 | 玉手箱・GAB・CAB のいずれか |
| `c-personal` | ヒューマネージ系 | TG-WEB |

この対応は、URL・受検画面から検査種別を見分ける方法として、複数の実務媒体で共通して言及される内容である。この判別表が典拠とするのは次の対策媒体であり、証拠グレードは C である。

- 出典: レバテックルーキー「適性検査 20 種類の見分け方！URL・WEB 画面から判断する方法」 https://rookie.levtech.jp/guide/detail/90170/ （グレード C。対策媒体）

## 使い方

- 判別は URL 文字列の照合のみで行う。URL への外部アクセスや、プロファイルの外部送信は伴わない。
- 判別結果は暫定であり、確度は「推定」とする。確定は Step 1 の `job-change-exam-scout` の調査（採用ページ・選考体験記の確認）で行う。

## 限界

判別には次の限界がある。Step 0 で暫定判別を伝える際は、これらを併せて示す。

- **ペーパー形式は判別できない。** 内田クレペリン検査のように紙で実施する検査は、受検 URL が存在しないため URL 判別の対象外である（出典: 前掲レバテックルーキー、グレード C）。
- **日本 SHL 系は単一の検査まで絞れない。** `e-exam`・`nsvs`・`tsvs` は日本 SHL の受検基盤であり、これらからは玉手箱・GAB・CAB のいずれかまでしか特定できない。最終的な種別は Step 1 の調査で確定する。
- **ドメインは変更されうる。** 検査提供元の受検基盤のドメインは、時期により変わる。判別表は現時点の対応であり、URL が表に一致しない場合や、一致しても実際の検査が異なる場合がある。URL 判別だけに依存せず、Step 1 の調査結果を優先する。
