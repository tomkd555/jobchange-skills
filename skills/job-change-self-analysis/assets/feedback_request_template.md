# 他者フィードバック依頼テンプレート

自己分析の他者視点（others_feedback）を集めるために、上司・同僚・部下・顧客・友人などへフィードバックを依頼する文面のテンプレートである。他者評価は自己評価より予測妥当性が高く、内省の限界を補う（詳細は references/self-analysis-methods.md）。

## 使い方

- 依頼相手に応じて、下の本文の `{相手}`・`{関係・期間}`・`{具体的な場面}` を書き換える。
- 質問は、人格評価（「私はどんな人か」）ではなく、行動と結果への紐付け（「どの行動が、どの結果につながったか」）を尋ねる形にする。フィードバックは、受け手の注意が課題から自己へ向くほど有効性が下がる。このため、課題志向で受け取る。
- 集めた回答は self_analysis.json の `others_feedback` に、`source_type`（上司／同僚／部下／顧客／友人・家族／評価面談）・`content`・`context`・`linked_episode_ids` の形で記録する。

## 依頼文（そのまま送れる本文）

依頼相手へ送る文面は、下の枠内をそのまま複製して用いる。相手への依頼文であるため敬体で書いてある。

```text
件名: 仕事の進め方について、率直なご意見をいただけますか

{相手} お世話になっております。

いま自分の仕事の進め方を振り返って整理しており、ご一緒した{関係・期間}の経験から、率直なご意見をいただけると助かります。お手すきのときで構いません。答えやすいものだけでも結構です。

1. 私が関わった仕事のうち、成果につながったと感じた場面はどれでしたか。そのとき、私のどの行動が効いていたとお考えでしょうか。
2. 逆に、私の進め方で改善したほうがよいと感じた点はありますか。どの場面で、どうすればよかったでしょうか。
3. 私が自分では気づいていない強みや行動の傾向があれば、教えてください。
4. 一緒に働くうえで、私に任せると安心できる仕事の種類はありますか。

具体的な場面（例:{具体的な場面}）に触れていただけると助かります。ご指摘ほど役立ちますので、遠慮なくお書きください。よろしくお願いいたします。
```

## 回答を記録するときの注意

- 「まじめ」「優秀」などの人格評価だけの回答は、可能なら「どの場面で・どの行動が」その印象につながったかを聞き返し、行動と結果へ紐付けてから記録する。
- 回答が自己認知と食い違う場合も、そのまま `content` に記録する。自己認知と他者認知の一致・不一致（ジョハリの窓）が、自己分析の手がかりになる。
- 依頼相手のメールアドレス・氏名などの個人情報は、外部サービスでの検索や送信に用いない。
